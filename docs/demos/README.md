# Demonstration

The real GNOME lock dialog in an isolated session, with a generated wallpaper and weather disabled.

- [GIF](lock-screen.gif) · [reduced-motion still](lock-screen-still.png)
- Source: [lock-screen-suite at `a5f98dc3b1d9`](https://github.com/spencernorton/lock-screen-suite/tree/a5f98dc3b1d91c9c4f97a5a2e60c1d8af1299cf2)
- Runtime: GNOME Shell 50.1 on Ubuntu 26.04, using an isolated home and session bus.
- 8 seconds; 48 frames; 60,142 bytes.
- GIF SHA-256: `3e19670653b05b5ea98c3a10d6ecbe104c9f2ab1c09e9febad6952685f8ed815`

Frames are captures of the real interface and are sampled at six frames per
second. The still and GIF contain only rendered pixels, without text metadata.
This is documentary footage; it does not establish a new package or hardware
qualification. Public source and normal CI remain the release evidence.
